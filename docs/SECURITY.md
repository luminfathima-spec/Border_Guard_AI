## 2. Authentication & Credential Hardening

1. **Password Security**:
   - Industry-standard **Bcrypt** hashing with adaptive work factors.
   - Salt generation per credential.
2. **Session Security**:
   - Cryptographically signed **HMAC-SHA256 JWT tokens**.
   - Configurable token expiration (default 24h).
   - Bearer scheme injection across API requests.

---

## 3. Forensic Evidence Chain of Custody

- **SHA-256 Checksums**: Every snapshot JPEG and clipped MP4 generated by the pipeline is hashed upon creation.
- **Tamper Evidence**: If media files on disk are modified, hash mismatch is instantly detectable during forensic audit.
- **Audit Logging**: Every analyst login, alert status change, and report generation is written to the immutable `AuditLog` database table.
