## 1. Annotated Claim Set Scaffold

### Claim 1 (Independent System Claim)

```text
[1.0] A distributed computer-vision perimeter surveillance and evidentiary verification system, comprising:
    a plurality of edge image capture devices positioned along a perimeter boundary, each edge image capture device comprising at least one processor, a local storage medium, and a network interface; and
    a central intelligence server communicatively coupled to the plurality of edge image capture devices;

[1.1] wherein each edge image capture device is configured to:
    ingest raw video frames and execute an object detection and multi-frame tracking model;
    evaluate target trajectory positions against a configurable virtual boundary polygon utilizing a point-in-polygon ray-casting evaluation; and
    generate a virtual boundary breach event only when target trajectory positions satisfy a temporal confirmation condition requiring inclusion within the virtual boundary polygon across a predetermined threshold of consecutive frames;

[1.2] wherein each edge image capture device further comprises an edge buffer controller configured to:
    buffer generated breach events and associated visual evidence metadata in a crash-safe local write-ahead logging database;
    assign a globally unique deterministic client identifier and a hardware-locked detection timestamp to each buffered breach event; and
    idempotently synchronize pending buffered breach events to the central intelligence server upon restoration of network connectivity without modifying the hardware-locked detection timestamp;

[1.3] wherein the central intelligence server comprises a provenance-aware event graph engine configured to:
    store ingested breach events, object tracks, camera sensors, and visual evidence records as nodes within a directed acyclic provenance graph; and
    interconnect nodes via explicit typed edges comprising direct observations, inferred associations, and contradictory relationships, wherein contradictory evidence creates non-destructive conflicting edges without overwriting preexisting observations;

[1.4] wherein the central intelligence server further comprises an adaptive verification controller configured to:
    compute an evidentiary sufficiency score for an ingested breach event based on detection confidence, object-track continuity, boundary penetration margin, and detected contradictory observations;
    determine whether the evidentiary sufficiency score satisfies a sufficiency threshold; and
    upon determining that the sufficiency score fails to satisfy the threshold, selectively dispatch a secondary local high-resolution frame resampling pass or a multimodal visual reasoning query to a generative foundation model subject to a bounded execution budget; and

[1.5] wherein the central intelligence server further comprises an anti-hallucinatory cross-examiner configured to:
    extract cited evidentiary identifiers and timestamp references from natural language incident reports generated by the generative foundation model;
    verify each extracted evidentiary identifier against actual stored database records in the provenance-aware event graph;
    flag any ungrounded claim citing an unverified or nonexistent identifier; and
    generate a cryptographic checksum digest binding verified factual claims to referenced visual evidence files.
```

### Claim 11 (Independent Method Claim)

```text
[11.0] A computer-implemented method for autonomous perimeter surveillance, evidentiary verification, and tamper-evident incident reporting, comprising:

[11.1] capturing video frames at an edge camera node, detecting and tracking moving targets, and evaluating target positions against a virtual boundary polygon using ray-casting point-in-polygon evaluation;

[11.2] confirming a boundary breach event only after a target sustains inclusion within the virtual boundary polygon across K consecutive frames, and storing confirmed breach events in an edge-local write-ahead logging buffer with a deterministic client UUID and an immutable detected timestamp;

[11.3] synchronizing buffered breach events from the edge-local buffer to a central server upon network availability, wherein the central server idempotently deduplicates received events based on the deterministic client UUID and preserves the immutable detected timestamp without temporal ingestion skew;

[11.4] constructing a vector-clocked directed acyclic event graph linking cameras, detections, tracks, breach events, and field observations via explicit typed edges, wherein contradictory observations are appended via non-destructive conflict edges without overwriting historical records;

[11.5] evaluating an evidentiary sufficiency vector for a breach event, and dynamically dispatching secondary high-resolution frame resampling or multimodal generative reasoning when the sufficiency vector indicates missing or conflicting evidence within a bounded cost budget; and

[11.6] cross-examining generative text incident reports by programmatically verifying every cited evidentiary identifier against actual database records, classifying statements into a multi-tier epistemic taxonomy, and computing a cryptographic hash digest binding the report to verified evidence files.
```

## 3. Dependent Claim Extensions (Claims 2–10 & 12–20)

- **Dependent Claim 2 (Spatial Temporal Confirmation)**: The system of Claim 1, wherein the temporal confirmation condition requires that an object centroid remain interior to the boundary polygon for at least $K=3$ consecutive frames sampled at an interval between $2$ and $5$ frames.
- **Dependent Claim 3 (Idempotent De-duplication)**: The system of Claim 1, wherein the central intelligence server enforces an idempotent deduplication database constraint on the deterministic client identifier, whereby duplicate transmissions during network reconnection storms are discarded without creating secondary event records.
- **Dependent Claim 4 (Priority Storage Pruning)**: The system of Claim 1, wherein the edge buffer controller prioritizes stored footage retention such that high-severity breach events are preserved indefinitely, while non-breach telemetry is pruned upon local storage utilization exceeding $90\%$ of the local storage medium.
- **Dependent Claim 5 (Vector Clock Cycle Detection)**: The system of Claim 1, wherein the provenance-aware event graph engine evaluates incoming relationship edges using depth-first search cycle detection to enforce a strictly directed acyclic graph topology.
- **Dependent Claim 6 (Multi-Criteria Sufficiency Formula)**: The system of Claim 1, wherein the evidentiary sufficiency score is calculated as a normalized linear combination of detection confidence, tracking dwell duration, boundary penetration distance, sensor availability, and inverse contradiction penalties.
- **Dependent Claim 7 (Bounded Budgeting & Unresolved State)**: The system of Claim 1, wherein the adaptive verification controller limits secondary verification passes to an iteration limit and a monetary API cost ceiling, and upon exhaustion without satisfying the sufficiency threshold, assigns a terminal state of `UNRESOLVED` to prevent hallucinated classifications.
- **Dependent Claim 8 (Epistemic Taxonomy Labels)**: The system of Claim 1, wherein the anti-hallucinatory cross-examiner categorizes each factual statement in the natural language incident report into one of: an optical observation, a computer-vision detection, a foundation model interpretation, or a human operator annotation.
- **Dependent Claim 9 (Cryptographic PDF Ledger)**: The system of Claim 1, wherein the anti-hallucinatory cross-examiner compiles the verified factual statements, referenced visual evidence hashes, and approval signatures into an immutable Portable Document Format (PDF) dossier associated with a SHA-256 checksum digest.
- **Dependent Claim 10 (Two-Step Consequential Action Gating)**: The system of Claim 1, further comprising a conversational surveillance copilot workstation configured to:
  receive natural language operator inquiries;
  route inquiries exclusively through authorized tool execution functions; and
  require a two-step confirmation protocol for consequential actions modifying operational threat levels, wherein read-only viewer roles are rejected and authorized operators must affirm a single-use action token before database mutation.
